## Git a GitHub – rychlá nápověda

### Běžné uložení a nahrání změn

```bash
git status
git add .
git commit -m "Popis provedených změn"
git push
```

### Naklonování existujícího repozitáře na jiném PC

```bash
git clone <url-odkaz-na-repozitar>
```

### Aktualizace již existujícího repozitáře na PC

```bash
git pull
```
